\# 🔐 SecureDocs - Sistema de Gestión de Expedientes con RBAC y ABAC



Aplicación web desarrollada en Python (Flask) que implementa un motor de autorización combinando dos modelos de control de acceso:

\- \*\*RBAC (Role-Based Access Control):\*\* Validación de permisos base asociados al rol del usuario.

\- \*\*ABAC (Attribute-Based Access Control):\*\* Evaluación de políticas basadas en atributos del usuario, recurso y contexto del entorno.
